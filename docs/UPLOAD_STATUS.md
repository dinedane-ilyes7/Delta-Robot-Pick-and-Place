# GitHub publication status

**Source of this publication:** the author's `deltarobot.zip`, an embedded CAD-v2 archive, and project preparation notes. This is a **collaborative robotics project**.

## Published

- CadQuery CAD generator and source modules (`cad/`)
- Delta kinematics analysis and a clearly marked reconstructed `analysis/params.py`
- Geometry configuration (`config/robot.yaml`)
- MuJoCo MJCF XML, body metadata and stored validation reports
- Source-only inverse/forward kinematics tests and GitHub Actions workflow
- 15 compressed CAD-render previews
- A compact, 11-page PDF preview of mechanical drawings (not the original print-quality file)
- Project README, scope and limitations

## Not yet published

- The pre-generated **61 STL mesh assets** referenced by the MuJoCo XML
- Original higher-resolution 11-page drawing PDF and large STEP exports
- Full-resolution render PNG files
- The separate full pick-and-place simulation/control application (`core/`, `sim/`, `ros2_ws/`), which was **not in this uploaded ZIP**
- Any physical demonstration or measured physical robot performance

## Collaboration / reuse

All contributors must receive appropriate credit. Public visibility is **not** the same as an open-source license. No license was added because redistribution and license terms must be agreed with the rights holders.

**Technical note:** The saved validation numbers come from the supplied archive, not tests newly run in GitHub. Only source-level syntax and basic kinematics have been checked automatically.
